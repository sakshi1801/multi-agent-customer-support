# Returns

## Return window
You can return any unused item within 30 days of delivery for a full refund.

## Eligible items
Items must be unused, undamaged and in their original packaging with all accessories. Used items can be returned only if they are faulty, in which case the warranty applies.

## Non-returnable items
Gift cards, downloadable software and opened hygiene products such as earphone tips cannot be returned unless they are faulty.

## How to start a return
Start a return from the Orders page of your account and choose the item. You do not need to contact support first.

## Return shipping label
Print the prepaid return label that is created when you start the return. Returns are free for the customer.

## Refund timing
Refunds appear within 5-7 business days after we receive the item and check it.

## Refund method
Refunds go back to the original payment method. We cannot refund to a different card or account.

## Exchanges
We do not offer direct exchanges. Return the item for a refund and place a new order for the product you want.

## Damaged on arrival
If an item arrives damaged, report it within 7 days of delivery with a photo. We will send a replacement or refund it, and you do not need to return the damaged item.

## Wrong item received
If you received the wrong item, contact support within 7 days. We will arrange a free pickup and send the correct product.
