# Orders

## Cancelling an order
Orders can be cancelled while their status is "processing". Once an order has shipped it cannot be cancelled, but you can return it after delivery.

## Changing an order
Items in an order cannot be edited. Cancel the order while it is still processing and place a new one.

## Order statuses
"Processing" means we are preparing your order. "Shipped" means it is with the courier. "Delivered" means it reached you. "Cancelled" means it was stopped and will not ship.

## Order confirmation
After you place an order you receive a confirmation email with your order number, which starts with ORD. Check your spam folder if it does not arrive within 15 minutes.

## Duplicate orders
If you placed the same order twice by mistake, cancel one of them while it is still processing. A cancelled order is refunded in full.
